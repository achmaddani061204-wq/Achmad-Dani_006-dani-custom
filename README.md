# Dani Custom Theme

Tema WordPress kustom untuk portofolio pribadi dengan desain modern, responsif, dan fokus pada tampilan landing page, artikel, halaman profil, kontak, serta hasil proyek.

## Fitur utama

- Header dan navigasi utama
- Hero section landing page
- Layout halaman home/front page
- Tampilan daftar artikel dan single post
- Halaman profil dengan minat, perjalanan belajar, pendidikan, dan proyek pilihan
- Halaman kontak dengan kanal sosial dan ajakan kolaborasi
- Sidebar dan footer widget
- Search page, archive, dan 404 page
- Support custom logo, featured image, dan menu navigasi
- Desain responsif untuk desktop dan mobile

## Struktur utama

- `header.php` — bagian kepala website
- `footer.php` — bagian footer website
- `front-page.php` — halaman utama / landing page
- `single.php` — tampilan detail artikel
- `archive.php` — tampilan arsip artikel
- `search.php` — hasil pencarian
- `functions.php` — registrasi tema, menu, widget, dan custom post type
- `style.css` — stylesheet utama tema
- `assets/` — aset frontend tambahan

## Instalasi

1. Salin folder `dani-custom` ke direktori `wp-content/themes/` di instalasi WordPress Anda.
2. Masuk ke dashboard WordPress.
3. Buka menu Appearance > Themes.
4. Aktifkan tema `Dani Custom`.
5. Jika diperlukan, atur menu utama lewat Appearance > Menus.

## Catatan

Tema ini dibuat untuk kebutuhan portofolio dan belum menutup kemungkinan untuk dikembangkan lebih lanjut sesuai kebutuhan proyek.

## Lisensi

Tema ini dibuat untuk kebutuhan pembelajaran dan pengembangan WordPress. Sesuaikan lisensi sesuai kebutuhan Anda.
